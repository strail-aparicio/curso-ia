# Glosario

Términos del curso en orden alfabético. Añade cada término nuevo en cuanto aparezca, con tus propias palabras.

| Término | Definición | Módulo |
|---------|------------|--------|
| **Alucinación** | Respuesta falsa que un modelo genera con total seguridad, porque produce lo probable y no lo verdadero | 0 |
| **Aprendizaje no supervisado** | El modelo busca estructura en datos sin etiquetas (por ejemplo, agrupar clientes) | 0 |
| **Aprendizaje por refuerzo** | Un agente aprende probando acciones y recibiendo premios o castigos | 0 |
| **Aprendizaje supervisado** | El modelo aprende a partir de ejemplos que incluyen la respuesta correcta (etiqueta) | 0 |
| **Deep Learning** | Machine Learning basado en redes neuronales con muchas capas | 0 |
| **Entrenamiento** | Proceso en el que el modelo ajusta sus reglas internas a partir de los datos | 0 |
| **Etiqueta** | La respuesta correcta asociada a un ejemplo ("spam" / "no spam") | 0 |
| **IA generativa** | Modelos que crean contenido nuevo: texto, imágenes, audio, código | 0 |
| **Inteligencia Artificial (IA)** | Campo que busca que las máquinas hagan tareas que requieren inteligencia | 0 |
| **Machine Learning (ML)** | Rama de la IA en la que el sistema deduce las reglas a partir de datos | 0 |
| **Predicción** | Usar un modelo ya entrenado para dar una respuesta sobre un caso nuevo | 0 |
| **Preprocesamiento** | Preparar los datos antes de usarlos (normalizar mayúsculas, limpiar, etc.) | 0 |
| **Sistema experto** | IA basada en reglas escritas a mano por especialistas (años 80) | 0 |
| **Transformer** | Arquitectura de red neuronal de 2017 en la que se basan los modelos de lenguaje actuales | 0 |
